# دليل تثبيت وتشغيل تطبيق Android — AutoLeadGen V3

## 1. نقل ملف APK إلى الهاتف عبر USB
1. قم بتوصيل هاتف Android بالكمبيوتر بواسطة كابل USB.
2. اسحب شريط الإشعارات على الهاتف واختر **نقل الملفات (File Transfer / MTP)**.
3. انسخ الملف التالي من جهاز الكمبيوتر:
   ```
   build\app\outputs\flutter-apk\app-release.apk
   ```
4. الصقه في مجلد **Downloads** أو المجلد الرئيسي في هاتفك.
5. افصل كابل الـ USB (لا يلزم توصيل الكابل بعد التثبيت إطلاقاً).

---

## 2. تثبيت التطبيق على الهاتف
1. افتح تطبيق **الملفات (Files)** على الهاتف وانتقل إلى مجلد **Downloads**.
2. اضغط على ملف `app-release.apk`.
3. إذا ظهر تنبيه "تثبيت التطبيقات من مصادر غير معروفة"، اضغط على **الإعدادات** وفعّل السماح من هذا المصدر.
4. اضغط **تثبيت (Install)** ثم **فتح (Open)**.

---

## 3. الاتصال بالكمبيوتر والتحكم عن بُعد
1. تأكد من تشغيل خادم V3 على الكمبيوتر بالنقر على:
   ```
   Start_V3_API.bat
   ```
2. تأكد من تفعيل اتصال **Tailscale** على الكمبيوتر والهاتف.
3. في شاشة الدخول بالتطبيق:
   - **Server URL:** أدخل عنوان Tailscale الخاص بالكمبيوتر مع المنفذ 8502:
     `http://100.x.y.z:8502`
   - **اسم المستخدم:** `admin`
   - **كلمة المرور:** `admin123`
4. اضغط **تسجيل الدخول والتحكم** — سيتصل التطبيق فوراً وتظهر شاشة التحكم بالكامل!
