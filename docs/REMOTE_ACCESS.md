# AutoLeadGen V3 — Remote Control via Tailscale

يتيح لك هذا الدليل التحكم الكامل في **AutoLeadGen V3** من هاتفك المحمول (أندرويد) من أي مكان في العالم مجاناً وبأمان تام ودون الحاجة لفتح منافذ في الراوتر (Port Forwarding).

---

## 1. كيف يعمل الاتصال عن بُعد؟

- يعمل خادم **FastAPI** على جهاز الكمبيوتر الخاص بك على المنفذ `8502` بعنوان `0.0.0.0:8502`.
- شبكة **Tailscale** تنشئ شبكة مشفرة خاصة (WireGuard Mesh VPN) بين هاتفك وجهاز الكمبيوتر.
- يمتلك جهاز الكمبيوتر عنوان IP مخصص داخل شبكة Tailscale (مثال: `100.x.y.z`).
- يتصل تطبيق الهاتف المحمول مباشرة بعنوان الـ IP هذا عبر بروتوكولات REST API و WebSocket.

---

## 2. خطوات الإعداد (5 دقائق فقط — مجاني 100%)

### الخطوة 1: تثبيت Tailscale على الكمبيوتر
1. حمّل البرنامج المجاني من [tailscale.com/download](https://tailscale.com/download) أو شغّل:
   ```powershell
   winget install Tailscale.Tailscale
   ```
2. سجّل الدخول بحساب Google أو Microsoft.
3. انسخ عنوان الـ Tailscale IP الخاص بالكمبيوتر (مثال: `100.82.140.21`).

### الخطوة 2: تثبيت Tailscale على هاتف Android
1. افتح متجر Google Play وابحث عن **Tailscale**.
2. سجّل الدخول **بنفس الحساب** الذي استخدمته على الكمبيوتر.
3. فعّل الاتصال (Connect).

### الخطوة 3: تشغيل الخادم على الكمبيوتر
- انقر نقراً مزدوجاً على الملف:
  ```
  Start_V3_API.bat
  ```
  أو شغّل:
  ```powershell
  python -m uvicorn api.main:app --host 0.0.0.0 --port 8502
  ```

### الخطوة 4: فتح تطبيق AutoLeadGen V3 على الهاتف
1. ثبّت ملف `app-release.apk` على هاتفك.
2. عند فتح التطبيق، أدخل:
   - **عنوان الخادم (Server URL):** `http://100.x.y.z:8502` (ضع الـ IP الخاص بك).
   - **اسم المستخدم:** `admin`
   - **كلمة المرور:** كلمة المرور التي عينتها.
3. اضغط **تسجيل الدخول** — ستظهر لوحة التحكم المباشرة فوراً!
