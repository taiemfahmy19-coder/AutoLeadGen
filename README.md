# 🎯 AutoLeadGen & AI Advertising Outreach Suite

> **Local-First / Free / Python**  
> نظام محلي متكامل لاكتشاف وتأهيل وتنظيم عملاء الإعلانات وتصميم المحتوى وفيديوهات الـ AI لأصحاب المشاريع الصغيرة.

---

## 🌟 الرؤية العامة للمشروع (Vision)

برنامج مكتبي محلي يساعدك على تحويل عملية الوصول للعملاء من:
`بحث يدوي ⬅ نسخ بيانات ⬅ جداول Excel ⬅ نسيان من تم التواصل معه`

إلى Pipeline منظم واحترافي:
`Search ⬅ Collect ⬅ Clean ⬅ Deduplicate ⬅ Score ⬅ Review ⬅ Message ⬅ Track ⬅ Export`

- **محلي بالكامل (Local-First):** يعمل على حاسوبك الشخصي دون الحاجة لسيرفرات سحابية أو اشتراكات شهرية.
- **مجاني 100% (No Paid APIs):** لا يتطلب مفاتيح API مدفوعة للعمل.
- **مخصص لخدمات الـ AI Advertising:** يقيس مدى ملاءمة كل نشاط تجاري لإعلانات وتصميمات وفيديوهات الـ AI تلقائياً.

## 🏗️ الهيكل البرمجي للمشروع (Architecture)

```text
AutoLeadGen/
│
├── app.py              # واجهة المستخدم التفاعلية (Streamlit UI)
├── config.py           # الإعدادات، القوالب، الحالات، وأوزان التقييم

├── cleaner.py          # تنظيف النصوص وتوحيد أرقام الهواتف (Phone Normalization)
├── deduplicator.py     # كشف التكرار الذكي (4 مستويات) ونظام دمج البيانات (Smart Merge)
├── scorer.py           # محرك تقييم العملاء (Lead Scoring من 0 إلى 100)
├── messenger.py        # إدارة التواصل بإشراف بشري وحظر DO_NOT_CONTACT
├── database.py         # قاعدة البيانات المحلية (SQLite) وسجل التفاعلات
├── exporter.py         # تصدير البيانات إلى Excel (.xlsx) و CSV بترميز UTF-8 BOM
├── logger.py           # سجلات التشغيل والتدقيق (app.log & Audit Log)
├── backup.py           # نظام النسخ الاحتياطي والاسترجاع الآمن لقاعدة البيانات
├── requirements.txt    # متطلبات التشغيل
├── README.md           # دليل الاستخدام والتوثيق
│
├── data/
│   ├── leads.db           # قاعدة بيانات SQLite
│   ├── backups/           # مجلد النسخ الاحتياطية
│   └── whatsapp_profile/  # مجلد جلسة WhatsApp Web المحلية
│
├── logs/
│   └── app.log            # سجل الأحداث
│
└── tests/
    ├── test_cleaner.py      # اختبارات التنظيف وتوحيد الهواتف
    ├── test_deduplicator.py # اختبارات المستويات الأربعة لكشف التكرار
    ├── test_database.py     # اختبارات قاعدة البيانات والدمج
    ├── test_scorer.py       # اختبارات حساب الـ Score ومطابقة النشاط
    └── test_backup.py       # اختبارات النسخ الاحتياطي والاسترجاع
```

## 🚀 التثبيت والتشغيل (Quick Start)

### 1. تثبيت المتطلبات:
```bash
pip install -r requirements.txt
```

*(اختياري لتفعيل متصفح Playwright للبحث الحي)*:
```bash
playwright install chromium
```

### 2. تشغيل البرنامج:
```bash
streamlit run app.py
```
ستفتح واجهة البرنامج مباشرة في المتصفح على العنوان `http://localhost:8501`.

## 🔬 الميزات الأساسية والـ Pipeline

### 1. توحيد وتطبيع أرقام الهواتف (`cleaner.py`)
- تحويل جميع الأرقام المصرية (010, 011, 012, 015) إلى الصيغة الدولية `+2010...`.
- دعم الأرقام ذات الرموز `+20` أو `0020`.
- دعم تحويل الأرقام المكتوبة بالأرقام العربية-الهندية (`٠١٢٣٤٥٦٧٨٩`).
- إزالة الفواصل والمسافات والشرطات تلقائياً.

### 2. كشف التكرار الذكي ونظام الدمج (`deduplicator.py`)
القاعدة: **One Real Business = One Lead**
- **المستوى الأول (الأقوى):** تطابق رقم الهاتف بعد الـ Normalization.
- **المستوى الثاني:** تطابق النطاق والموقع الإلكتروني.
- **المستوى الثالث:** تشابه قوي في (اسم النشاط $\ge 70\%$) + (العنوان $\ge 60\%$).
- **المستوى الرابع:** تشابه في اسم النشاط + تطابق آخر 8 أرقام من الهاتف.
- **نظام الدمج (Smart Merge):** عند اكتشاف تكرار، لا يتم حذف السجل عشوائياً، بل تُدمج الحقول الناقصة في السجل الأساسي (Master Record) مع حفظ سجل الدمج في `merge_history`.

### 3. تقييم العملاء (`scorer.py`)
كل عميل يحصل على تقييم من **0 إلى 100**:
| المعيار | الوزن |
| :--- | :---: |
| هاتف صالح وموحد | 25 |
| موقع إلكتروني / صفحة نشاط | 15 |
| اكتمال الاسم والعنوان | 15 |
| وضوح النشاط والمجال | 15 |
| ملاءمة النشاط لإعلانات وفيديوهات الـ AI | 25 |
| جودة وتكامل البيانات | 5 |

*مثال:* محل عطور كامل البيانات يحصل على تقييم **95-100/100**، بينما العميل ببيانات ناقصة يحصل على حوالي **45/100**.

### 4. الـ CRM المحلي وسجل التفاعلات (`database.py`)
حالات دورة حياة العميل:
- `NEW`: عميل جديد لم يُراجع.
- `QUALIFIED`: تمت مراجعته ومناسب للخدمة.
- `READY`: جاهز في طابور التواصل.
- `CONTACTED`: تم التواصل معه.
- `REPLIED`: قام بالرد.
- `INTERESTED`: مهتم بالخدمة.
- `NOT_INTERESTED`: غير مهتم.
- `DO_NOT_CONTACT`: **ممنوع التواصل نهائياً** (محمي برمجياً ومستبعد دائماً).
- `INVALID`: بيانات غير صالحة.

### 5. مركز الرسائل وقوالب العروض (`app.py` & `config.py`)
- يدعم اللغتين العربية والإنجليزية.
- استبدال ديناميكي للمتغيرات: `{name}`، `{business}`، `{industry}`، `{city}`.
- قوالب مخصصة للعطور، المطاعم، المدرسين، والشركات.
- الباقة الافتراضية محددة: 1500 جنيه (8 تصميمات + 2 فيديو Reels) مع تفاصيل الفيديوهات الإضافية.

### 6. طابور التواصل والإشراف البشري (`messenger.py`)
- لا توجد رسائل عشوائية أو Spam.
- توليد روابط واتساب مباشرة (`https://wa.me/...`) بنص مخصص بنقرة واحدة.
- التحقق الصارم من سياسة `DO_NOT_CONTACT`.
- تسجيل كل تفاعل تلقائياً مع التاريخ والملاحظات في جدول `interactions`.

### 7. النسخ الاحتياطي والتصدير (`backup.py` & `exporter.py`)
- إنشاء نسخ احتياطية بضغطة زر باسم: `leads_YYYY-MM-DD_HHMMSS.db`.
- استرجاع أي نسخة سابقة بأمان مع عمل نقطة استعادة تلقائية قبل الاسترجاع.
- تصدير فوري إلى Excel (`leads.xlsx`) و CSV يدعم الحروف العربية بالكامل (`utf-8-sig`).

## 🛡️ سياسة الأمان والخصوصية
1. البيانات تُحفظ محلياً بالكامل على جهازك في `data/leads.db`.
2. لا تُشارك مجلد `data/whatsapp_profile/` لأنه يحتوي على ملفات الجلسة المحلية.
3. التزم بالإشراف البشري والتأخير الزمني (180 - 300 ثانية) لتجنب حظر حسابات المراسلة.
